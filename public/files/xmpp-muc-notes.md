# XMPP MUC — заметки для интеграции Messthon

## 1. Подключение к конференции
- MUC использует отдельный домен, например `conference.example.org`.
- JID комнаты: `room@conference.example.org`.
- Ник участника задаётся в `<presence><x xmlns="http://jabber.org/protocol/muc"/></presence>`.

## 2. История
- История запрашивается через `maxstanzas`, `maxchars` или `since`.
- Для Messthon достаточно загружать последние 50 сообщений при первом открытии.
- Приватная история может быть отключена администратором комнаты.

## 3. Роли и аффилиации
- Роли: visitor, participant, moderator.
- Аффилиации: owner, admin, member, none, outcast.
- Интерфейс должен различать права на отправку сообщений и модерацию.

## 4. OMEMO в MUC
- OMEMO для MUC требует отдельной проверки поддержки участниками.
- Не показывать замок «зашифровано» для комнаты, если не все сообщения защищены.
- Ключи устройств публикуются через PEP.

## 5. Что проверить в Messthon
- Отображение MUC отдельно от личных чатов.
- Статус присутствия участников.
- Индикатор непрочитанных сообщений без ложных read receipts.
